The problem Dr. Verdon is solving

Generalist AI tools like Microsoft Copilot are built for primary care, not the complex coding and documentation needs of specialists. Hospital data sits fragmented across Epic (often 25-plus separate integrations), PACS imaging, dictation, and legacy EMRs, creating technical debt and coding errors that trigger clawbacks. Dr. Verdon's response is analytics-driven triage at Bon Secours Mercy Health: getting the sickest patients seen first and removing friction between patient and physician.

Angles for the conversation

What to lead with when this goes in front of Bon Secours Mercy Health leadership.

1

Billing-first, not tech-first

Dr. Verdon was explicit: hospital systems resist new technology unless it's tied directly to revenue. Lead every conversation with the physician revenue story (roughly $4M to $8M/year), not the AI.

2

Mid-market moves faster

Large systems have slow governance boards. Self-funded, mid-sized practices like Dayton Neurospine iterate quickly — this pilot is the fast proof point before a Bon Secours Mercy Health-wide conversation.

3

Data is a flywheel, not a report

The Springfield, Ohio case: the real backlog cause was a local pain-management gap, not MRI delays. Frame this as continuous optimization work, not a one-time integration project.

Acronyms, in plain English

The alphabet soup this brief uses, decoded.

Bon Secours Mercy Health — the health system hosting the pilot, already running AWS infrastructure for Epic disaster recovery
CPT — Current Procedural Terminology — the billing code set for what was done in an encounter
ICD-10 — the diagnosis coding standard used for billing and clinical tracking
PACS — the imaging system storing and distributing scans
EMR — electronic medical record
Prior authorization — payer pre-approval required before a treatment is covered
Clawback — an insurer reversing a payment after a post-hoc audit finds a coding or billing error
