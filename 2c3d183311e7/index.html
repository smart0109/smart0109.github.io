The Integration Pitch

Why Vorro, why NMDP, why now

NMDP already solved the hardest platform problem: a modern, secure API and integration backbone (WSO2) carrying SOAP and REST traffic for a registry of 43 million donors and 420+ network members, with Salesforce wired in for donor registration. That's a real, working foundation most global health networks don't have.

But every new transplant center, apheresis center, cord blood bank or international registry that joins the network is still running its own EHR (Epic, Oracle Health, MEDITECH, or a country-specific system abroad), and each one needs its own connector built and maintained against that backbone.

That's exactly the layer Vorro (BridgeGate EiPaaS) adds underneath: 800+ pre-built healthcare connectors (HL7, FHIR, EHR, LIS, HIE) that plug into an existing API layer like WSO2 instead of replacing it. Every new center NMDP recruits becomes a Vorro connector, not a bespoke integration project, right as the network scales past 150,000 transplants and adds EBMT and HRSA partners.
